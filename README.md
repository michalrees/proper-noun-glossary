# 专有名词整理 Skill

此仓库保存可复用的术语整理规则及校验工具，不包含个人词表和本地文献。

- `SKILL.md`：录入、查证、格式、作者和修订记录规则。
- `check.py`：词表结构自检工具。

使用时让代理读取 `SKILL.md`，并指定词表位置。默认只解释词义；用户要求收录或整理时才写入词表。

```bash
python3 /path/to/proper-noun-glossary/check.py /path/to/专有名词.md
```

不传词表路径时，脚本查找当前工作目录的 `专有名词.md`。路径不存在时会提示并退出，不创建词表。

Python 3.9 或以上即可运行；可选依赖 `pypinyin` 用于中文分区和拼音排序，缺少时会提示跳过这两项检查。

作者规则、LaTeX 公式、汇总词条及逐次修改记录格式以 `SKILL.md` 为准。
