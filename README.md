# 专有名词整理

以气候变化科学为主的术语表与代理整理规则，也收录机器学习、统计等相关术语。

- [专有名词.md](专有名词.md)：按字母分区的术语表。
- [SKILL.md](SKILL.md)：录入、出处核实、字段格式和维护规则。
- [check.py](check.py)：结构自检脚本。

## 使用

让代理先读取本目录 `SKILL.md`，再按需求解释、收录或修订术语。每条包含释义、特点、出处、易混点、相关词汇、收录时间和记录人；公式统一使用 LaTeX，优先使用行间公式。

```bash
python3 check.py
```

Python 3.9 或更新版本可运行。可选依赖 `pypinyin` 用于中文分区与拼音排序；缺少时会提示跳过相应检查。

词表中的部分出处使用 Obsidian 本地笔记链接，公开仓库不包含这些笔记。
